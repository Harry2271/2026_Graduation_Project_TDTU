  How It Works

  ┌────────┬────────────────────────────────────┬──────────────────────────────┐
  │  Mode  │              Trigger               │           Behavior           │
  ├────────┼────────────────────────────────────┼──────────────────────────────┤
  │ NAV    │ Pi sends heartbeat + move commands │ Autonomous navigation        │
  ├────────┼────────────────────────────────────┼──────────────────────────────┤
  │ MANUAL │ Pi disconnects but web connected   │ Web/manual control only      │
  ├────────┼────────────────────────────────────┼──────────────────────────────┤
  │ SAFE   │ No Pi signal, no web               │ All motors braked            │
  ├────────┼────────────────────────────────────┼──────────────────────────────┤
  │ E-STOP │ D key or web button                │ All motors hardware-disabled │
  └────────┴────────────────────────────────────┴──────────────────────────────┘

  LiDAR Integration (Pi Side)

  The Pi sends one of these JSON commands when it detects an obstacle:
  {"cmd":"obstacle_left"}     // → strafe right, slow forward
  {"cmd":"obstacle_right"}    // → strafe left, slow forward
  {"cmd":"obstacle_front"}   // → stop forward, rotate CW
  {"cmd":"obstacle_clear"}   // → resume normal navigation

  Web Manual Control

  1. Edit include/WiFiCredentials.h with your WiFi network
  2. Flash with pio run
  3. Open http://<ESP32-IP> in a browser
  4. Use buttons or keyboard (W/A/S/D + Q/E) for manual control

  LED indicator: fast blink = E-stop, medium = safe, slow = manual, very slow = nav
